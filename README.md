# React Interview Prep

My technical interview preparation notes, based on Jonas Schmedtmann's *The Ultimate React Course* and the projects I build while studying.

Questions and answers are grouped by course section. Each question is tagged with a level:

- **[Junior]**: core concepts every junior React developer should know
- **[Strong junior]**: deeper "why does it work this way" questions
- **[Middle]**: architecture, performance and trade-offs
